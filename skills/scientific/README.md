# scientific

科研流程里的技能：读文献、写材料、出交付物。

和 [`../common-ground/`](../common-ground/) 相反——那一类产出共识，这一类产出**文件**。

## 技能

**[`sci-read-paper`](sci-read-paper/)** — 把一篇 AI/ML 论文读成一份可追溯的中文精读报告。单文件离线 HTML，八章正文加一份完整证据台账。偏蛋白、小分子与药物发现方向。不做摘要，不做翻译。

**[`sci-cn-disclosure`](sci-cn-disclosure/)** — 把论文稿、源码、运行结果转成中国发明专利技术交底书，交学校知识产权办公室与专利代理所。权利要求逐条溯源到论文行号与源码行号。产出交底书，不产出可直接递交国知局的四件套。

## 共同点是校验器，不是模板

两个技能各有一个**交付前必须 exit 0** 的检查程序（`validate_report.py`、`check_all.py`），没过就不算写完。凡是能从固定集合里选的、能数的、能对上号的，都由程序判定；要判断的才留给人。

这比「照着模板写」强，因为模板靠人照抄，校验器靠程序拦截。加新技能时，先想清楚**它的交付物怎么被机器验**——那比 SKILL.md 写成什么形状重要。
