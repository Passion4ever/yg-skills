# sci-cn-disclosure

把论文、源码、运行产物、附图、发明人笔记，转成**中国发明专利技术交底书**，交学校知识产权办公室与专利代理所。

## 它不做什么

- **不产出可直接递交国知局的四件套**（权利要求书 / 说明书 / 说明书附图 / 说明书摘要）——那是代理师的活
- **不做查新，不给可专利性结论**——只为背景技术做定向检索，并在动笔前查一次「这个发明有没有被申请过」
- **不能保证出处本身没被读错**——校验器只能验「台账 ↔ 文档」一致，验不了「台账 ↔ 事实」

## 依赖

六个 `check_*.py` 是纯标准库，校验 Markdown 不用装任何东西；校验代理师发回的 `.docx` 要 `python-docx`。

出稿另需 `latex2mathml` `Pillow`，画图需 `cairosvg` 与**系统中文字体**——字体缺了渲出来是一片空心方框，所以开工前先跑一次自检：

```bash
python scripts/render_figures.py --check-env
```

## 用法

直接说「帮我写份技术交底书，材料在 xxx 目录」。技能会走完下面八步，**每一步有门禁，没过就停在那一步**——后一步不替前一步补漏，带着问题往下走一步，回头改的代价就翻一倍。

**0 · 信息采集** — 填表头，如实记公开状态（时间、地点、形式，以及它与六个月宽限期、第 24 条三种例外的关系）。然后按发明人姓名与申请人机构检索**同一发明有没有在先申请**——这一步在写任何一个字之前做完，因为已有在先申请会改变后面全部工作的前提。

**1 · 源材料映射与核实** — 清点工作目录，逐个表态（读了 / 与本发明无关 / 打不开）；通读主文档并逐节表态。凡是将进入权项、公式或效果表的数值，清点它在材料里有几个载体，两个以上的逐一对；只有一个载体的标明是孤证。有源码时另做一遍**不带清单的通读**，专门撞那些没人想到要问的实现缺陷。

**2 · 证据台账** — 每条候选特征记下表述、来源、作用、效果，以及四选一的支持状态：`explicit`（有记载）、`inherent`（常规实施裕度）、`needs-confirmation`（貌似合理但无记载）、`unsupported`。后两者**不得写入权利要求**。降级之前先把论文全文、配置文件、运行产物、消费该值的代码四处查空。

**3 · 权利要求** — 把特征分成必要特征链（→ 独权）与优选细化（→ 从属权）。这个划分是交底书最有价值的东西，代理师做不了。独权写成闭环：技术输入 → 相互配合的操作 → 具体的领域产物。

**4 · 说明书** — 法定五节。背景技术每条已知路线都要给出**机理层面**的缺陷，并引专利文献而非只有学术文献。效果对比表按证据强度序位取数并注明测试条件。深度标定的标准是"同行照此不再做研发能不能实现"。写完在这里做**首轮实质评审**——权项与说明书刚成型，是改动代价最低的位置。

**5 · 可替代实施方式** — 先用 `--extract` 抽出待办清单，逐项处置，最后才动笔。权项里每一个数值都要有交代：标 `essential`，或给出替代方案与依据。这是全篇最容易编造的一节，而在此处编造会触发第 26.3 条公开不充分。

**6 · 附图** — 权利要求 1 里每一组成组的步骤都应有一张图对得上。渲染后**逐张看过**：汉字有没有变成空心方框、标签有没有压住连线、连线有没有穿过方框、文字有没有出界、缩到三分之二还认不认得清。这五样校验器查不出来。

**7 · 出稿与评审** — 渲成 docx，独立公式为原生 OMML（代理师可双击编辑）。就首轮之后**改动过的部分**再评审一次，然后跑交付门禁。

交付前跑一次全套：

```bash
python scripts/check_all.py 交底书.md
```

**任一 ERROR 不得交付。WARNING 不阻断，但每条都要过一遍**——零错误不等于可以交，合格判据见 `references/delivery-contract.md`。

## 目录

```
SKILL.md                              常驻上下文 —— 流程与判断标准

references/delivery-contract.md       交付前逐条核对 —— 唯一的合格判据
references/template-disclosure.md     写说明书时读 —— 只管形式，不管判断
references/alternatives-discipline.md 写可替代实施方式时读 —— 举证纪律
references/figure-standards.md        画附图时读 —— 该画哪几张、验收标准
references/examiner-review.md         外部评审时读 —— 提示词模板与已知失误模式

scripts/check_all.py                  【入口】一条命令跑完下面五个
  ├ check_complete.py                 交付物是否齐全
  ├ check_claims.py                   权项结构
  ├ check_evidence.py                 权项特征 ↔ 证据台账
  ├ check_alternatives.py             具体选择枚举 ↔ 替代方案台账
  └ check_figures.py                  附图编号、附图标记 ↔ 正文

scripts/render_figures.py             附图 spec → SVG + PNG
  └ vendor/figure_renderer.py         基础渲染器
scripts/render_disclosure.py          Markdown → docx（公式为原生 OMML）
scripts/read_source.py                .md / .docx 统一读取
scripts/math_to_omml.py               LaTeX → Word 公式域
```
