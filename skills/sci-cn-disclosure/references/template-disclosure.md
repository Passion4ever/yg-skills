# 技术交底书模板

此文件只管**形式**:骨架、编号、标点、章节顺序。**任何判断都不在这里**——写什么、写多深、怎么取舍,见 SKILL.md 各阶段。

交底书本身无法定格式要求。下列结构是国内高校知产办与代理所普遍习惯的形态,照用可减少来回沟通。**若目标单位另有自己的模板,以对方模板为准**,本文件退化为一份检查清单:对照看看对方模板里有没有漏掉这里列出的要素。

---

## 一、表头

正文之前、无标题,逐行:

```
申请类型：发明

发明专利申请时请求提前公布，提实质审查请求（该项可缩短审查周期，但技术方案会提前被公众所知）

申请人：<单位全称>

发明人：<姓名，姓名，……>

第一发明人身份证号：<号码>

技术联系人：<姓名，手机号>

邮箱：<邮箱>

您好！请您务必核准基于目前说明书公开文字，本领域技术人员是否无需再作进一步研发即可
实现本申请的发明目的（即技术方案是否清楚、完整，是否能够解决本申请提出的技术问题）；
若不能，则说明目前文本公开不充分，在审查意见答复阶段该缺陷就无法克服，导致本申请被
驳回，无法获得授权。
```

要点:

- 第二行是**勾选项**,由发明人决定留或删。提前公布可缩短审查周期,但技术方案提前公开。
- 最后那段是**代理所要发明人本人核准的公开充分性声明**。起草者不得代为确认——交稿时必须提示发明人逐条读过说明书后自行判断。
- 有校外合作单位时,`申请人` 需列全,影响共同申请人资格与后续权属,须向发明人确认。

## 二、权利要求书

标题独占一行:`权利要求书`

编号用阿拉伯数字加英文句点:`1.` `2.` ……,编号前不冠"权利要求"或"权项"。

### 独立权利要求

```
1. 一种<发明名称>，其特征在于，包括以下步骤：

1）<第一步骤名>：

<该步骤的技术内容，分号分隔>；

2）<第二步骤名>：

2.1）<子步骤>；

2.2）<子步骤>；

……

n）<末步骤：以具体产物或控制动作收尾>。
```

惯例:

- 顶层步骤用 `1）2）3）`,子步骤用 `2.1）2.2）`,均为全角右括号。
- `其特征在于` 作为前序部分与特征部分的过渡语。
- 步骤内一律用分号;句号只出现在整条权利要求的末尾。

### 从属权利要求

```
2. 根据权利要求 1 所述的<发明名称>，其特征在于，<附加技术特征>。
```

- 每条必须增加技术限定;仅陈述优点不构成限定。
- 引用必须在先。多项引用用"根据权利要求 1 至 12 中任一项所述的……"。
- 沿若干条独立的技术轴布置回退位(网络规模 / 训练细节 / 生成参数 / 后处理 / 应用扩展),而不是把同一轴切成很多份。

### 尾部两条(计算机实施方法的常规配套)

```
n. 一种计算机可读存储介质，其上存储有计算机程序，其特征在于：所述计算机程序被处理器
执行时实现权利要求 1 至 m 中任一项所述方法的步骤。

n+1. 一种电子设备，其特征在于：包括处理器和计算机可读存储介质；所述计算机可读存储
介质上存储有计算机程序，所述计算机程序被所述处理器运行时执行权利要求 1 至 m 中任一
项所述方法的步骤。
```

## 三、说明书

标题独占一行:`说明书`,其下发明名称独占一行。

五个部分,标题与顺序法定,不可改动、不可增删:

```
技术领域
背景技术
发明内容
附图说明
具体实施方式
```

### 技术领域

一段。写明所属技术领域与具体主题。

### 背景技术

分段列举已知路线,每条一段。写什么、引什么见 SKILL.md 阶段 4。

### 发明内容

三个小节:

```
发明目的      —— 要解决的技术问题
本发明的构思  —— 技术方案，用语与权利要求对齐
本发明的优点  —— 每条优点绑定到具体技术手段
```

效果对比表可置于此节或具体实施方式。交底书可自由使用表格。

### 附图说明

每图一句:`图N为……。` 附图标记在此或具体实施方式中首次引入,格式 `1—部件名称`。

### 具体实施方式

按实施例编号:`实施例一：……`。每个实施例对应一种**实质不同的实施方式**,不是发明内容的复述。

推荐的实施例组织:

1. 实施例一 —— 主实施方式,完整走通全部步骤,给出具体参数取值
2. 实施例二…N —— 各类实施变体(换对象、换初始化方式、换应用场景)
3. **可替代实施方式** —— 逐项列举各技术选择的替代,见 `alternatives-discipline.md`
4. 补充说明 —— 兜底次要参数 + 存储介质/电子设备实施 + 通用免责句

### 说明书摘要

放在说明书末尾,术语与权利要求 1 一致。

## 四、附图

放在文末,每图配图题,以 `![图N](figures/figN.png)` 插入。该画哪几张、画到什么程度见 `figure-standards.md`。

## 五、附件

支撑材料(数据清单、序列表、原始结果)另附,不进说明书正文,供代理师参考。
