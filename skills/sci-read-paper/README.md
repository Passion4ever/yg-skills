# sci-read-paper

把一篇 AI/ML 论文读成一份**可追溯的中文精读报告**：单文件、离线可读的 HTML，八章正文加一份完整证据台账。侧重蛋白、小分子与药物发现方向。

## 它不做什么

- **不是摘要，也不是翻译**——不做中英对照，也不为「这篇论文里 X 是多少」这种单点提取而启动
- **不判断论文该不该发**——它判断的是「论文的证据支持到哪一句为止」，这两件事不一样
- **不把计算结果当成实验事实**——对接打分不是实测亲和力，自洽性判据不是实验验证的结构
- **不能保证读对**——校验器只验形式与溯源，验不了推理本身。一条边界写得中立而完整，和一条边界写歪了，机器分不出来

## 依赖

**没有依赖。** 两个脚本都是纯标准库，任何 Python 都能直接跑。

## 用法

直接给论文即可——PDF 路径、标题、DOI、arXiv 号、期刊页面或官方仓库都行，比如「10.48550/arXiv.1706.03762 帮我深度精读」。技能会走完下面八步：

**1 · 选模式** — 默认 `standard`。只有明确要求穷尽审计、准备复现、完整实验矩阵或逐文件代码比对时才用 `audit`，它会在正文之后多加四块折叠面板。配图默认不出。

**2 · 取材料与核实** — 按证据强度取用：论文与补充材料 → 官方代码与配置 → 数据集文档 → 一手文献。取代码时只做原始文件请求或稀疏检出，**先看远端文件树、排除权重路径**——这个领域的仓库常年跟踪几个 G 的检查点，一次普通 clone 能在论文还没读之前就把预算烧光。`standard` 模式下外部核验最多做三个结论关键的主张族。

**3 · 建立背景** — 第 1 章先把**模型字面上收什么、预测什么**说死，并与采样代理、生物机理分开；再讲这件事为什么难、主流怎么做、本文切在哪个缺口。第 2 章压成三分钟能读完的一张地图。

**4 · 跟住一条样本** — 第 4、5 章从**一条具体样本**出发，看它怎样被选中、切分、编号，进入训练，再在模型内部一步步变形。每一步记形状、记丢掉了什么、记论文与代码是否一致。模块清单不算数——那是目录不是解释。

**5 · 按问题组织实验** — 第 6 章一个研究问题一张实验卡，不按论文表格顺序。八个字段固定：作者要回答什么、实验类型、怎样设计、改了什么控了什么、数据与指标、实际观察到什么、作者据此主张什么、证据边界。**观察与作者的解读分开写。**

**6 · 切换到审稿人** — 第 7 章才开始判断。前六章每提出一条证据边界，都带着 `Bnn` 编号与类型声明（冲突 / 缺失 / 外部核验 / 推断 / 事实），第 7 章必须逐条兑现：要么在审查卡里处理，要么列进「无实质影响」。**一条被丢掉的边界，往往正是那个错掉的结论所关于的。**最后给四档判定：可以相信 / 可以暂时相信 / 当前不能推出 / 被现有证据否定。

**7 · 出稿** — 用脚手架生成骨架，再逐个占位符填。模板已经烤进八章标题、章节编号、速览三行、判定网格——这些每份报告都一样的东西不用打字，也就错不了。卡片、边界、台账行、引用一律从片段库整块复制。

```bash
python3 scripts/new_report.py --slug <paper-slug> --outdir <目录>
```

**8 · 校验** — 交付前必须退出 `0`，没过就不算写完。

```bash
python3 scripts/validate_report.py <报告.html>
```

## 校验器管什么

20 组检查，其中 6 个是**封闭词表**——实验类型、影响五档、判定四档、台账六类标签、边界五种类型、审计四块面板。凡是从固定集合里选的，机器验集合；凡是要判断的，留给人。

它还管：八章齐全且顺序正确、每条证据引用都指向存在的台账行、每条边界都被兑现且台账里有对应类型的行、判定用语不得出现在第 1–6 章、只能用模板定义的 CSS 类、句子不超过 120 字且不超过 4 个分句、每千汉字的英文词种数不超过 40、报告自己记录的模式与实际结构一致。

**它验不了推理对不对。** 那部分见 `../../tests/sci-read-paper/rubric.md`。

```
SKILL.md                              常驻上下文 —— 流程与最终检查

references/output-contract.md         写报告时读 —— 每章要建立什么、契约细则
references/evidence-policy.md         取材料时读 —— 来源次序、标签、取码守则
references/ai-ml-reading-guide.md     读论文时读 —— 怎么想，不是写什么
references/bio-chem-validity.md       蛋白 / 小分子 / 药物发现方向才读

assets/report-template.html           页面外壳 + 样式 + 八章骨架（35 个占位符）
assets/fragments.html                 10 种标准片段 + 它们的封闭词表

scripts/new_report.py                 按模式生成骨架，解析出待填清单
scripts/validate_report.py            20 组检查 —— 交付的唯一机器判据
```
